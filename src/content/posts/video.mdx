在文章里嵌入视频很简单。把视频文件放进 `public/assets/videos/`，封面图放进 `public/assets/images/`，然后用 `VideoCard` 组件引入即可。封面会在播放前显示，点击中间的播放按钮才开始播放。

## 用法

在 `.mdx` 文章顶部引入组件：

```jsx
import VideoCard from "@/components/features/VideoCard.astro";
```

然后传入视频地址 `src`、封面 `poster`（可选）和标题 `title`（可选）：

```jsx
<VideoCard
  src="/assets/videos/linglong-yuekui-sword.mp4"
  poster="/assets/images/video-posters/linglong-yuekui.webp"
  title="视频标题"
/>
```

## 平台视频（iframe）

YouTube 或 Bilibili 的视频，直接复制平台的嵌入代码粘贴进来也可以：

```html
<iframe width="100%" height="468" src="https://www.youtube.com/embed/5gIf0_xpFPI" title="YouTube video player" allowfullscreen></iframe>
```
